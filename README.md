## Projects

**[lockin-validate](https://github.com/joaquitodom/lockin-validate)**: an offline Python toolkit that checks whether a backtest or a financial model can be trusted. It audits inputs, rebuilds results from trades, flags look-ahead and overfitting, and validates alpha signals, ML models, VaR/ES backtests, forecasts, portfolio weights and live track records. Every finding links to its evidence. Comes with a [working paper](https://github.com/joaquitodom/lockin-validate/blob/main/paper/lockin-validate-paper.pdf) on what went wrong in our own strategy's holdout test.

**[get-a-job-kit](https://github.com/joaquitodom/get-a-job-kit)**: a job-search assistant for Claude Desktop (profile, tailored CVs, daily search, application tracker).
